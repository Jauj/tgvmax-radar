📈 Suivi & historique des disponibilités

Chaque relevé mémorise le nombre de trains Max Jeunes d'un tronçon pour toutes les dates de voyage de la fenêtre de réservation. Vu dans le temps, ça révèle les ouvertures de places (annulations, mises en vente) et les épuisements — pour savoir exactement quand réserver.

⚙️ Snapshot quotidien automatique & sauvegarde des données

…

Pour un relevé chaque nuit, même sans visiter le site : un robot GitHub Actions relève automatiquement les tronçons listés dans data/watched.json. Le bouton « Préparer » copie ce fichier à jour — colle-le dans le dépôt (Add file → Create new file → nom data/watched.json → Commit) et le snapshot devient automatique.

☁️ Sauvegarde en ligne optionnelle (Supabase)

L'historique fonctionne déjà sans aucun compte (mémoire de ce navigateur + snapshot public du dépôt). Pour sauvegarder aussi chaque instantané en ligne (partagé entre tes appareils) :

  1. Crée un projet sur supabase.com/dashboard
  2. Ouvre SQL Editor → New query et colle le contenu du fichier supabase-setup.sql → Run
  3. Copie l'URL du projet et la clé anon (Settings → API) dans supabase-config.js

Outil indépendant, non affilié à la SNCF. Disponibilités indicatives de l'offre Max Jeunes (dataset open data « tgvmax », champ historique od_happy_card, mis à jour chaque nuit) — réserve sur SNCF Connect.

Données : SNCF Open Data (licence ODbL) · Carte : OpenStreetMap / CARTO · Aucun tracker, aucune limite.
