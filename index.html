📈 Suivi d'évolution des places

Cet onglet enregistre chaque jour le nombre de places Max Jeunes d'un trajet et trace la courbe dans le temps :places qui remontent = des annulations, fonce réserver · places qui fondent = ça se vend, arrête d'attendre.

Pour l'activer, il faut le connecter à un projet Supabase (gratuit, 3 minutes) :

  1. Crée un projet sur supabase.com/dashboard
  2. Ouvre SQL Editor → New query et colle le contenu du fichier supabase-setup.sql → Run
  3. Copie l'URL du projet et la clé anon (Settings → API) dans supabase-config.js

📸 L'instantané compte les places du jour et l'ajoute à l'historique. ➕ « Suivre » fait la même chose automatiquement à chaque visite (1× par 12 h), tant que ce trajet reste dans ta liste.

Outil indépendant, non affilié à la SNCF. Disponibilités indicatives de l'offre Max Jeunes (dataset open data « tgvmax », champ historique od_happy_card, mis à jour chaque nuit) — réserve sur SNCF Connect.

Données : SNCF Open Data (licence ODbL) · Carte : OpenStreetMap / CARTO · Aucun tracker, aucune limite.
